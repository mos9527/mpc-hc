# MPC-HC Custom

[![Build](https://github.com/mos9527/mpc-hc/actions/workflows/build.yml/badge.svg)](https://github.com/mos9527/mpc-hc/actions/workflows/build.yml)
[![Nightly Builds](https://img.shields.io/badge/mpc-builds-cyan)](https://nightly.link/mos9527/mpc-hc/workflows/build/develop?preview)

Custom MPC-HC build with additional features. Mostly for music playback.

Builds are available from [nightly](https://nightly.link/mos9527/mpc-hc/workflows/build/develop?preview).

## Additional Features

- GitHub CI builds
- `.lrc` (embedded or external) lyrics support in Audio-only view, rendered via Internal Subtitle Renderer with expanded style settings. Shown as a panel or as subtitles, either optionally in tategaki (vertical writing, with its own font option).
- `Floating` (shortcut: <kbd>5</kbd>, to enable and cycle) view preset for Audio-only view with multiple modes
